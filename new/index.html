หน้าตาร้าน

2รับเงิน

ใส่พร้อมเพย์ของคุณเอง — เงินลูกค้าโอนเข้าบัญชีคุณโดยตรง เราไม่เคยแตะเงินของคุณ ลองสแกน QR ในตัวอย่างทางขวาด้วยแอปธนาคาร ดูได้เลยว่าขึ้นชื่อคุณจริงไหม

รับเก็บเงินปลายทาง (COD) ด้วย

3ช่องทางคุยกับลูกค้า

ลูกค้ากดสั่งเสร็จ ระบบจะก๊อปรายการ+ที่อยู่ให้ แล้วเปิดแชทนี้ให้เขาวาง

หาลิงก์เพจ: เปิดเพจในเฟซบุ๊ก → ปุ่มส่งข้อความ → คัดลอกลิงก์ · ไลน์: LINE OA → หน้าโปรไฟล์ → คัดลอกลิงก์

4ค่าส่ง

ใส่ได้หลายแบบ ลูกค้าเลือกเองตอนสั่ง · ใส่ 0 = ส่งฟรี

5สินค้า

แตะกรอบรูปเพื่อใส่รูปสินค้า · รูปถูกย่อในเครื่องคุณเอง ไม่ได้อัปขึ้นเน็ต

6ส่งให้เราเปิดร้านให้

กดโหลดไฟล์ร้าน แล้วส่งไฟล์นั้นมาในแชท เราเอาไปเปิดเป็นลิงก์ร้านจริงให้

ข้อมูลทั้งหมดอยู่ในเครื่องคุณเท่านั้น — หน้านี้ไม่มีการส่งอะไรออกไปที่ไหนเลย ถ้าปิดหน้าไปแล้วเปิดใหม่ในเครื่องเดิม ของที่กรอกไว้ยังอยู่ แต่ถ้าเปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์จะหาย ฉะนั้นกรอกเสร็จแล้วโหลดไฟล์เก็บไว้ด้วย
